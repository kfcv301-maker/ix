# 用户 TLS / UDP 限制

在 **用户管理 → 管理隧道 → 分配 / 编辑授权** 中设置。策略属于一条用户隧道授权，只影响该用户在该隧道下的入口转发；其他用户、其他隧道与出口节点不受影响。管理员账号（role_id=0）始终不限制。

| 设置 | 行为 |
| --- | --- |
| TCP：不限制 | 允许 TLS 和非 TLS |
| TCP：只允许 TLS | 只允许以 TLS ClientHello 开始的 TCP 连接 |
| TCP：禁止 TLS | 拒绝 TLS ClientHello，允许非 TLS TCP |
| 允许 UDP：关闭 | 禁止该用户在本隧道入口的原生 UDP 转发 |

识别 TCP 外层握手，不终止 TLS、不校验证书或 SNI。AnyTLS 和使用 TLS ClientHello 的 REALITY 连接可以用于“只允许 TLS”。非 TLS 加密协议属于非 TLS；“禁止 TLS”不能证明其余流量是否加密。该功能不是完整的加密验证或任意协议防伪检测。

UDP 开关与 TLS 策略独立。关闭 UDP 会阻止直接使用 UDP 的 QUIC、Hysteria2、TUIC 等，但不会阻止 AnyTLS 等 TCP/TLS 连接内部承载的 UDP。

已有授权默认 TLS 不限制、UDP 允许。面板管理的入口服务采用各用户授权策略，覆盖旧节点级 HTTP/TLS/SOCKS 开关；未纳入用户策略的旧服务保留原有行为。

更改时热更新对应入口服务，无需重启节点。收紧 TCP 策略会关闭该用户受影响的已有 TCP 连接，收紧 UDP 策略只关闭其 UDP 会话；其他用户和管理员的连接保持可用。重复同步或放宽策略不会主动断开连接。

保存后的“待同步”状态保留到所有入口节点确认，离线或失败的节点会重试。策略同时保存到 Agent 配置，暂停恢复及节点重连都会复核；单调递增的策略版本防止旧同步命令覆盖新设置，历史授权 ID 对应的服务也会一并更新。

此功能需要配套更新面板后端、前端和入口 Agent。旧 Agent 不支持策略命令时显示待同步；新建受限制转发也会要求节点明确报告支持该功能，避免默默忽略限制。管理员豁免旧节点级开关同样需要新的入口 Agent。
